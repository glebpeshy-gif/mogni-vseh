# Картинки для «Могни всех»

Положите PNG с прозрачным фоном в эту папку (src/art) — игра подхватит их сама вместо эмодзи.
Имена файлов — только латиница, без пробелов (требование Яндекс Игр).
Размер: примерно 512×512, персонаж по центру. Имена файлов — строго такие:
