# Картинки для «Могни всех»

Положите PNG с прозрачным фоном в эту папку (src/art) — игра подхватит их сама вместо эмодзи.
Имена файлов — только латиница, без пробелов (требование Яндекс Игр).
Размер: примерно 512×512, персонаж по центру. Имена файлов — строго такие:

## Фоны (необязательно) — папка bg/
Сейчас фоны генерируются в коде: у каждого соперника и босса свои цвета, узор и стикеры.
Чтобы поставить свою картинку, положите PNG 720×1280 с именем как у соперника:
bg/normis.png, bg/tiktoker.png, … bg/boss_king.png

Один общий фон на всех: bg.png прямо в src/art/
