# Публикация на Яндекс Играх — пошагово

Консоль: https://yandex.ru/games/console

## 1. Собрать архив
```bash
npm run zip
```
Получится `mogni-vseh.zip`. `index.html` лежит в корне архива,
имена файлов латиницей (требование 1.22), размер ~2 МБ (лимит 100 МБ).

Картинки для консоли уже лежат в папке `promo/`. Пересобрать их можно так:
`node tools/make-promo.mjs` (иконка и обложки), скриншоты — через `tools/shot.mjs` (см. комментарий в нём).

## 2. Создать игру в консоли
«Добавить приложение» → тип **HTML5**, название «Могни всех».

### Вкладка «Лидерборды»
Создать лидерборд — без него окно «Топ» в игре покажет ошибку:
| Поле | Значение |
|---|---|
| Техническое название | `mogs` (именно так, его ищет код в `src/sdk.js`) |
| Название ru / en | `Топ могеров` / `Top moggers` |
| Тип | Числовой, по убыванию |
| Основной лидерборд | ✅ |

Очки — сколько соперников игрок замогал за всё время. Попасть в таблицу может только
игрок, вошедший в аккаунт Яндекса: в окне «Топ» для остальных есть кнопка «Войти».
Вне Яндекс Игр (локально, GitHub Pages) окно показывает ботов — это тестовый режим.

### Вкладка «Реклама»
- **Sticky-баннеры:** включить для мобильных (портрет — снизу) и для десктопа.
  Галочку «Использовать API для показа sticky-баннера» можно не ставить — код поддерживает оба варианта.
- Полноэкранная реклама и реклама за награду включены по умолчанию, ничего делать не нужно.

### Вкладка «Финансы» / партнёрская программа
Чтобы реклама приносила деньги, в консоли должны быть заполнены платёжные данные
(раздел «Финансы») — это делаете сами, в коде ничего менять не надо.

## 3. Загрузить архив
Вкладка **«Версии» → «Загрузить архив»** → `mogni-vseh.zip`.

## 4. Проверить черновик
Открыть игру кнопкой «Открыть с debug-панелью» (или добавить `?debug-mode=16` к адресу).
В левом нижнем углу должно быть `IT` — SDK подключён верно. Реклама в черновике тестовая.

- [ ] После стартовой рекламы игра начинается, звук не играет поверх рекламы
- [ ] Свернуть вкладку → звук и бой останавливаются, вернуться → продолжаются
- [ ] «📺 РЕКЛАМА: ×2 МОГ» → после просмотра эффект включается
- [ ] Закрыть рекламу за награду раньше времени → награды нет, появляется подсказка
- [ ] Победить босса → окно итогов → «ДАЛЕЕ» → полноэкранная реклама → следующий соперник
- [ ] Проиграть боссу → «📺 +15 СЕК» даёт ещё попытку, «ПОНЯЛ» откатывает на уровень назад
- [ ] Колесо: бесплатный спин, затем спины за рекламу
- [ ] «Топ»: таблица грузится, после входа в аккаунт ты в ней появляешься
- [ ] Обновить страницу → прогресс на месте
- [ ] Настройки: смена языка, звуки, музыка, вибрация, тряска — всё сохраняется после перезагрузки
- [ ] С компьютера: пробел — мог, 1–8 — прокачка, Esc — закрыть окно
- [ ] «Шмот»: вещи покупаются за 💅 и видны на персонаже

## 5. Отправить на модерацию
Кнопка «Отправить на модерацию». Обычно проверяют от нескольких дней до пары недель.
Если вернут с замечаниями — в письме будет номер требования, его можно найти в
https://yandex.ru/dev/games/doc/ru/concepts/requirements

## Что уже сделано в коде (src/sdk.js)
| Требование | Как сделано |
|---|---|
| 1.19.1 подключение SDK | `/sdk.js` относительным путём, `YaGames.init()` |
| 1.19.2 LoadingAPI.ready | вызывается, когда главный экран готов |
| 1.19.3 GameplayAPI | `stop` в окнах, на рекламе, при паузе; `start` — когда снова можно играть |
| 1.19.4 пауза платформы | `game_api_pause` / `game_api_resume` останавливают игру и звук |
| 1.3 потеря фокуса | свёрнутая вкладка / потеря фокуса = пауза и тишина |
| 1.9 сохранения | локально сразу после действия, в облако не чаще раза в 5 сек и при сворачивании |
| 4.4 реклама не мешает игре | полноэкранная — только после нажатия «ДАЛЕЕ» в итогах босса |
| 4.5 реклама за награду | на каждой кнопке 📺 написано «реклама» и что даёт; награда — только бонус |
| 4.7 пауза на рекламе | игра и звук стоят, пока открыта реклама |
| 2.14 язык | автоопределение через `ysdk.environment.i18n.lang`, переключатель в настройках |
| 6.2 / 6.3 звук и пауза | звуки и музыка отключаются в настройках, при потере фокуса — плашка «Пауза» |
| 6.9 выбор языка | названия языков на родном языке: «Русский», «English» |
| Лидерборд | настоящий `leaderboards` SDK, лидерборд `mogs`, вход через `auth.openAuthDialog` |
